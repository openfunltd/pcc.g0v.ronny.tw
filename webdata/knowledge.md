## 這份文件是給誰看的

`pcc-api`（本資料集）本身**不是政府採購網的官方 API**，而是本專案作者爬取「[政府電子採購網](https://web.pcc.gov.tw/)」逐日公告的 HTML 頁面、解析成結構化 JSON 後對外提供的第三方服務。要正確解讀這個 API 回傳的欄位（例如 `unit_id`、`brief.type`、`job_number`、押標金/決標金額等），需要一點政府採購法制的背景知識，這份文件就是整理這些背景知識，並附上可驗證的法規來源。

法規解釋以法規原文及主管機關（[行政院公共工程委員會](https://www.pcc.gov.tw/)）之公告、函釋為準，本文僅摘要供理解 API 資料脈絡使用。

## 制度架構總覽

台灣政府採購的法源是一部法律（政府採購法）加上一批由主管機關依授權訂定的子法規（施行細則、辦法、標準、準則）：

```
政府採購法（法律，立法院制定）
    │  第113條：施行細則由主管機關定之
    ▼
政府採購法施行細則（命令）
    │  法條中大量「...辦法/標準/準則，由主管機關定之」的具體授權
    ▼
各項辦法／標準／準則（命令，行政院公共工程委員會訂定）
    如：招標期限標準、押標金保證金暨其他擔保作業辦法、
        政府採購公告及公報發行辦法、採購申訴審議規則 等
```

主管機關為**行政院公共工程委員會**（政府採購法第 9 條，法規原文用語為「行政院採購暨公共工程委員會」）。
[來源: 政府採購法 第9條, LawID `A0030057`, 最後修正 2019-05-22, https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=A0030057]

用 `tw.gov.moj~ref~law` 查 `LawCategory=行政＞行政院公共工程委員會＞通用目`（精確比對）可以列出目前掛在此分類下的現行有效法規，共 66 筆——**注意這 66 筆裡混有技師法、工程技術顧問公司管理條例、災後重建特別條例等非採購法子法規**（因為都由同一機關主管），不能直接當作「政府採購法子法規清單」使用；下方「與本 API 資料相關的子法規」表格是已對照政府採購法各條文授權出處、確認屬於採購法體系的子法規。
[查詢方式: `?LawCategory=行政＞行政院公共工程委員會＞通用目&LawAbandonNote=&per_page=100`，資料集 `tw.gov.moj~ref~law`]

## 核心概念與本 API 欄位的對應

### 1. 採購的定義與招標方式

政府採購法第 2 條：「本法所稱採購，指工程之定作、財物之買受、定製、承租及勞務之委任或僱傭等。」第 7 條進一步定義工程／財物／勞務三大類。這對應到 pcc-api 各筆記錄 `brief` 裡的公告標的分類。
[來源: 政府採購法 第2、7條, LawID `A0030057`]

招標方式分三種（第 18 條）：
- **公開招標**：公告方式邀請不特定廠商投標
- **選擇性招標**：先公告辦理資格審查、建立合格廠商名單，再邀請投標
- **限制性招標**：不經公告，邀請二家以上廠商比價或一家廠商議價（第 22 條列舉 16 款得採限制性招標的情形，例如緊急事故、專屬權利、原有採購後續擴充等）
[來源: 政府採購法 第18、22條, LawID `A0030057`]

### 2. 決標方式：最低標 vs. 最有利標

決標原則（第 52 條）：
1. 訂有底價者，底價內最低標得標
2. 未訂底價者，預算內最低標得標
3. **最有利標**：依招標文件評審標準做綜合評選（技術、品質、功能、商業條款、價格等），評選辦法由主管機關另定
4. 複數決標

機關辦理公告金額以上之專業服務／技術服務／資訊服務／社會福利服務／文化創意服務，**以不訂底價之最有利標為原則**（第 52 條第 2 項）。
[來源: 政府採購法 第52條, LawID `A0030057`；最有利標評選辦法, LawID `A0030080`, 最後修正 2025-01-21]

pcc-api 的 `tender`/搜尋類端點回傳的 `detail` 欄位中若有「決標方式」「評分」「總序位」等 key，就是對應這裡的決標原則判斷結果。

### 3. 公告金額 / 查核金額 / 巨額採購門檻

採購金額門檻決定要用哪種招標方式、要不要監辦、要不要適用巨額採購的特定資格規定。**具體門檻金額不在政府採購法或施行細則本文，而是在「投標廠商資格與特殊或巨額採購認定標準」中明訂巨額採購門檻**：

| 採購類型 | 巨額採購門檻 |
|---------|-------------|
| 工程採購 | 新臺幣 2 億元 |
| 財物採購 | 新臺幣 1 億元 |
| 勞務採購 | 新臺幣 2,000 萬元 |

[來源: 投標廠商資格與特殊或巨額採購認定標準 第8條, LawID `A0030099`, 最後修正 2015-10-29, https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=A0030099]

「公告金額」與「查核金額」則由主管機關另行公告（政府採購法第 13 條「公告金額應低於查核金額，由主管機關參酌國際標準定之」），**這兩個門檻本身是主管機關的行政公告數值，不是法規條文，不在全國法規資料庫的查詢範圍內**——若使用者問「現在公告金額是多少」，應請其查行政院公共工程委員會官網的最新公告，不要用本資料庫的數字回答（本資料庫查無此數值）。
[來源: 政府採購法 第13條, LawID `A0030057`]

採購金額的計算方式（分批辦理、複數決標、租期不確定等如何合併計算）規定在施行細則第 6 條。
[來源: 政府採購法施行細則 第6條, LawID `A0030058`, 最後修正 2021-07-14]

### 4. 押標金

機關辦理招標應要求廠商繳納押標金（勞務採購原則上免收；未達公告金額之工程財物採購得免收；議價方式得免收押標金）。
[來源: 政府採購法 第30條, LawID `A0030057`]

押標金額度上限：**以不逾預算金額或預估採購總額之 5% 為原則（一定比率則不逾標價 5%），但不得逾新臺幣 5,000 萬元**。廠商有虛偽投標、借用他人名義投標、得標後拒不簽約等情形，押標金不予發還並得追繳（第 31 條列舉 7 款情形）。
[來源: 押標金保證金暨其他擔保作業辦法 第9條, LawID `A0030079`, 最後修正 2019-11-18；政府採購法 第31條, LawID `A0030057`]

### 5. 等標期（招標公告到截止投標的天數下限）

| 採購金額級距 | 公開招標最短等標期 |
|-------------|------------------|
| 未達公告金額 | 7 日 |
| 公告金額以上未達查核金額 | 14 日 |
| 查核金額以上未達巨額 | 21 日 |
| 巨額採購 | 28 日 |

[來源: 招標期限標準 第2條, LawID `A0030093`, 最後修正 2009-08-31, https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=A0030093]

### 6. 「刊登公報」與「不刊登公報」——對應本專案爬蟲的兩種列表來源

`PLAN.md` 提到爬蟲有 `list/{ymd}.html.gz`（刊登公報）與 `list/np-{ymd}.html.gz`（不刊登公報）兩種列表來源，這個區分**直接對應「政府採購公告及公報發行辦法」規定的兩種公開層級**：

- **應刊登採購公報**（第 4 條）：招標公告、決標結果或無法決標之公告、變更補充公告、拒絕往來廠商刊登、年度重大採購效益評估等，屬於法規明訂「應刊登政府採購公報」的公告類型。
- **僅公開於採購網站，未達公告金額者才需要，必要時才刊登公報**（第 6 條第 3 款）：「未達公告金額採購之決標公告」屬於這一類——**這就是本專案「不刊登公報」（np-）列表資料的法源依據**，也是為什麼這批公告數量遠多於刊登公報的公告，但檢索管道不同（不會出現在政府採購公報，只在採購網站上）。

[來源: 政府採購公告及公報發行辦法 第4、6條, LawID `A0030065`, 最後修正 2008-05-20, https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=A0030065]

### 7. 決標公告 vs. 無法決標公告——對應本專案的 URL 分類

`Entity.php` / `Parser.php` 依政府採購網原始連結格式把公告分成四類（`aaa-` = award 決標、`ttd-` = tender 招標、`anaa-` = nonAward 無法決標、`idpr-` = tpRead 招標文件閱覽），這對應法規上的公告種類：

- **招標公告**：政府採購法第 27 條，機關辦理公開招標或選擇性招標應公告
- **決標結果公告**：政府採購法第 61 條，機關應於決標後一定期間內公告決標結果；決標公告應登載之事項（機關、標的、決標日期、得標廠商、決標金額、招決標方式等）明訂於「政府採購公告及公報發行辦法」第 13 條
- **無法決標公告**：同樣依政府採購法第 61 條「無法決標者，亦同」辦理，登載事項（招標方式、無法決標事由、是否繼續辦理採購等）明訂於同辦法第 15 條，**且應於廢標後二週內、重行招標前公告**

[來源: 政府採購法 第27、61條, LawID `A0030057`；政府採購公告及公報發行辦法 第13、15條, LawID `A0030065`]

### 8. 拒絕往來廠商——查詢公司相關 API 時要注意

政府採購法第 101～103 條規定：機關發現廠商有虛偽投標、借用證件投標、得標後拒不簽約、驗收不合格情節重大等 15 款情形之一，經通知廠商陳述意見後，會將廠商名稱刊登政府採購公報，並在一定期間（3 個月至 3 年不等，依情節）內禁止該廠商參加投標或作為決標對象、分包廠商。

**這代表用 `searchbycompanyname`/`searchbycompanyid` 查到的公司紀錄，可能包含被刊登拒絕往來紀錄的廠商**——但 pcc-api 目前的欄位設計（`brief`/`companies`）**不會特別標註「此為拒絕往來公告」**，需要 AI 自行從 `brief.type`／`detail` 內容判斷該筆公告是否為第 101～103 條性質的公告，不能假設所有查到的公司紀錄都是「正常得標」。
[來源: 政府採購法 第101-103條, LawID `A0030057`]

### 9. 特別預算——`searchallspecialbudget`/`searchbyspecialbudget` 的法源

pcc-api 的 `searchbyspecialbudget` 端點依據的「特別預算」概念**不是來自政府採購法，而是預算法**。預算法第 83 條規定，行政院於年度總預算外，因下列情事之一得提出特別預算：
1. 國防緊急設施或戰爭
2. 國家經濟重大變故
3. 重大災變
4. 不定期或數年一次之重大政事

特別預算之審議程序準用總預算規定，但前三款因應緊急需要者得先支付其一部（第 84 條）。實務上如「前瞻基礎建設計畫」「新式戰機採購特別預算」「疫後特別預算」等都是依此條文編列，其下的採購案會在 pcc-api 資料中被標記對應的特別預算名稱。
[來源: 預算法 第83、84條, LawID `T0020001`, 最後修正 2021-06-09, https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=T0020001]

### 10. 其他常見子法規概念（統包／共同投標）

- **統包**（第 24 條）：將工程或財物採購中之設計與施工、供應、安裝或一定期間之維修等併於同一採購契約辦理招標，實施細節見「統包實施辦法」。
- **共同投標**（第 25 條）：二家以上廠商共同具名投標、共同具名簽約、連帶負履行責任，實施細節見「共同投標辦法」。

[來源: 政府採購法 第24、25條, LawID `A0030057`；統包實施辦法, LawID `A0030063`；共同投標辦法, LawID `A0030064`]

## 使用範例：查證本文法規事實

```bash
# 查政府採購法全文（含決標原則、押標金、申訴等章節）
curl -H "Authorization: Bearer YOUR_TOKEN" \
  "https://data.openfun.tw/api/v1/datasets/tw.gov.moj~ref~law/records/A0030057"

# 查巨額採購門檻的原始條文
curl -H "Authorization: Bearer YOUR_TOKEN" \
  "https://data.openfun.tw/api/v1/datasets/tw.gov.moj~ref~law/records/A0030099"

# 查特別預算的定義（預算法）
curl -H "Authorization: Bearer YOUR_TOKEN" \
  "https://data.openfun.tw/api/v1/datasets/tw.gov.moj~ref~law/records/T0020001"

# 列出行政院公共工程委員會主管的現行法規（含非採購法子法規，需自行篩選）
curl -H "Authorization: Bearer YOUR_TOKEN" \
  --data-urlencode "LawCategory=行政＞行政院公共工程委員會＞通用目" \
  --data-urlencode "LawAbandonNote=" \
  --data-urlencode "per_page=100" \
  -G "https://data.openfun.tw/api/v1/datasets/tw.gov.moj~ref~law/records"
```

## 重要限制

1. **本 API 非官方資料源**：pcc-api 是第三方爬蟲整理的資料，欄位命名（如 `unit_id`）是本專案自訂，不是政府採購法或政府採購網的官方用語；官方用語與欄位對應關係見上方各節。
2. **公告金額／查核金額的具體數字不在法規本文**，屬主管機關行政公告，本資料庫查不到，回答使用者時應明確告知需查行政院公共工程委員會官網最新公告，不可用本文的巨額採購門檻數字去反推公告金額或查核金額。
3. **法規為現行版本快照**：本文所引條文為查詢當下之現行有效版本（`LawAbandonNote` 為空），政府採購法及子法規歷年多次修正，若使用者問「某個舊決標案適用的規則」，應留意公告日期是否早於條文最後修正日，必要時提醒使用者條文可能已修正。
